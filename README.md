# digital_diary
https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage
I have used java script to handle my program by using two separate arrays and local storage items  to store  the users input, allowing the program to easily differentiate 
between the titles and the main bodies of the cards the user has saved. The program uses for loops to cycle through all the items in each array after the program removes
them from local storage and pushes them there, and then uses the appendChild node to create a display for them all. The for loops are only carried out when the the  
parameters in the if statements ,which check if local storage items are empty or not, are met creating a fail safe to sop the program from creating empty cards
